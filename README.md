# promptshift

**How robust are SAM and MedSAM to imperfect prompts?** CS 5330 Team 04 (Ruoyu Wang, Hao Wang, Jiani He).

Promptable segmentation models are usually evaluated with near-perfect box prompts taken from the ground truth. We perturb the prompts on purpose (box shift, box scale, click offset), measure the Dice drop of SAM ViT-B, SAM ViT-H and MedSAM, and compare against a supervised U-Net that needs no prompt.

Phase 1 = the full framework plus a pilot on Kvasir-SEG. See `CLAUDE.md` for the full spec.

## Run on Colab

The repo is public, so no token is needed. For each notebook in order: *File → Open notebook → GitHub* → `geekRoy0126/promptshift` → `notebooks/…`; *Runtime → Change runtime type → T4 GPU*; *Runtime → Run all*. (If the repo is made private again: add a read-only GitHub token as the Colab secret `GH_TOKEN` with *Notebook access* on; the setup cell then uses it. Never paste a token into a cell or a file.)

| Notebook | What it does | Time (T4, rough) |
|---|---|---|
| `P1_00_setup_colab` | weights (SAM ViT-B / ViT-H, MedSAM, checksums verified) and data (Kvasir-SEG, COCO and ISIC annotations, BUSI) to Drive; records Colab versions | 10–15 min |
| `P1_01_data_check` | `check_data.py` for all four datasets on Colab; split files and `docs/data_stats.md` must match the repo | 15–20 min |
| `P1_02_medsam_parity` | MedSAM vs. official script (Dice ≥ 0.99) and SAM ViT-B / ViT-H vs. `SamPredictor` (identical) on GPU | 5 min |
| `P1_03_kvasir_box_pilot` | Kvasir pilot: 200 test images × 3 models × 24 configs; integrity check; report tables; qualitative examples; downloads a results zip | 30–60 min |
| `P1_04_unet_kvasir` | U-Net baseline: train on 700 images (60 epochs, resumable), pick best val Dice, test on the same 200 images; downloads a results zip | 20–30 min |

Each notebook starts with a parameters cell and a shared setup cell (mount Drive, fetch the repo (with `GH_TOKEN` if set), `pip install -e .`). Data, weights and results live in `MyDrive/promptshift/`; rerunning a notebook skips finished work, so after a disconnect just *Run all* again. The notebooks are generated by `scripts/build_notebooks.py`: edit that, then run it.
