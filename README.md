# promptshift

**How robust are SAM and MedSAM to imperfect prompts?** CS 5330 Team 04 (Ruoyu Wang, Hao Wang, Jiani He).

Promptable segmentation models are usually evaluated with near-perfect box prompts taken from the ground truth. We perturb the prompts on purpose (box shift, box scale, click offset), measure the Dice drop of SAM ViT-B, SAM ViT-H and MedSAM, and compare against a supervised U-Net that needs no prompt.

Phase 1 = the full framework plus a pilot on Kvasir-SEG. See `CLAUDE.md` for the full spec.

## Run on Colab

Once per Google account:

1. Create a GitHub **fine-grained token** with read access to this repo only (Contents: Read-only).
2. In Colab, open the 🔑 *Secrets* panel, add it as `GH_TOKEN`, and switch on *Notebook access*. Never paste the token into a cell or a file.

Then, for each notebook in order: *File → Open notebook → GitHub* (tick *Include private repos*) → `geekRoy0126/promptshift` → `notebooks/…`; *Runtime → Change runtime type → T4 GPU*; *Runtime → Run all*.

| Notebook | What it does | Time (T4, rough) |
|---|---|---|
| `P1_00_setup_colab` | weights (SAM ViT-B / ViT-H, MedSAM, checksums verified) and data (Kvasir-SEG, COCO annotations) to Drive; records Colab versions | 10–15 min |
| `P1_01_data_check` | `check_data.py` on Colab; split files and `docs/data_stats.md` must match the repo | 3–5 min |
| `P1_02_medsam_parity` | MedSAM vs. official script (Dice ≥ 0.99) and SAM ViT-B / ViT-H vs. `SamPredictor` (identical) on GPU | 5 min |
| `P1_03_kvasir_box_pilot` | Kvasir pilot: 200 test images × 3 models × 24 configs; integrity check; report tables; downloads a results zip | 30–60 min |

Each notebook starts with a parameters cell and a shared setup cell (mount Drive, fetch the repo with `GH_TOKEN`, `pip install -e .`). Data, weights and results live in `MyDrive/promptshift/`; rerunning a notebook skips finished work, so after a disconnect just *Run all* again. The notebooks are generated by `scripts/build_notebooks.py`: edit that, then run it.
